EDITING
Static headings, copy and links are in the root HTML pages. All styles are in css/site.css.
Interactive behaviour and its content are in the single readable js/site.js bundle (search for the named component or text). React runtime is included; do not edit its library sections.
Interactive sections carry data-now-component markers. Their HTML is a reading fallback; JavaScript renders those sections when enabled, so change interactive copy in the shared JavaScript, not only its fallback HTML.
The original typed authoring source is retained separately for future substantial edits.

REVIEW ONLY

YouTube films connect externally only when opened.
All HTML has noindex; robots disallows crawling. Configure X-Robots-Tag where your host supports it; _headers is host-specific. Noindex is not access control or a secrecy guarantee.
